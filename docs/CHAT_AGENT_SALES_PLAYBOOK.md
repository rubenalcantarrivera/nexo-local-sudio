# Nexo Chat Agent Sales Playbook

## Posicionamiento

Nexo Chat Agent es un add-on para páginas web de negocios locales. Ayuda a responder preguntas frecuentes, explicar servicios y preparar al cliente para escribir por WhatsApp.

Pitch:

> Además de la página, podemos integrar un asistente inteligente que responde preguntas frecuentes, explica servicios y prepara al cliente para escribir por WhatsApp. No reemplaza al equipo; funciona como primera atención.

## Cuándo ofrecerlo

- El negocio recibe muchas preguntas repetidas.
- Tiene servicios que requieren explicación.
- Depende de citas, reservas o cotizaciones.
- Ya usa WhatsApp como canal principal.
- Quiere verse más profesional desde celular.

## Objeciones

**¿Va a reemplazar a mi equipo?**
No. Reduce preguntas repetidas y pasa a WhatsApp cuando se requiere atención humana.

**¿Puede agendar solo?**
En la primera fase prepara la conversación y abre WhatsApp. La confirmación final la hace el equipo.

**¿Puede equivocarse?**
Sí, por eso se configura con límites, disclaimers y escalamiento a humano.

**¿Puede responder precios?**
Solo si están definidos. Si no, guía al cliente a WhatsApp para confirmar.
